# 날리지포인트 홈페이지 리뉴얼 — 시안 C (Signal)

날리지포인트(KnowledgePoint) 회사 홈페이지 리뉴얼 디자인 시안 C입니다.
캔버스 없이 브라우저에서 바로 열리는 정적 페이지로 정리했습니다.

## 보는 방법

- `index.html`을 브라우저(크롬 권장)로 열면 됩니다.
- PC·모바일 겸용 반응형입니다. 창 폭을 720px 이하로 줄이거나 개발자도구 기기 모드로 보면 모바일 화면이 나옵니다.
- 영상 자동재생이 막히면 로컬 서버로 열어주세요: `npx serve .` 또는 `python3 -m http.server`

## 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 시안 C 페이지 (PC·모바일 반응형) |
| `dc-shim.js` | 페이지 템플릿·상태를 그려주는 경량 런타임 |
| `assets/` | 이미지, 로고, 히어로 영상(RCS·OTA, PC/모바일), Pretendard 폰트 |

## 디자인 기준

- 컬러: 네이비 `#1B2A88`, 시안 `#13B5EA`, 화이트
- 폰트: Pretendard (Variable)
- 디자인 원본: Figma "시안 C — Signal 메인 (1440 / 모바일 390)" 프레임과 "시안 C — 모션 가이드" 메모

## 모션 요약

1. **인트로 (첫 방문 1회, 약 5.4초)**: 백지 → 작은 점 점등 → 큰 점 점등 → 붓 획으로 비행 → 헤더를 가로지르며 로고·메뉴 등장 → 한 박자 쉬고 히어로
2. **혜성 커서 (PC)**: 시안 점이 마우스를 따라오며 꼬리, 멈추면 은은한 발광, 버튼에 닿으면 링
3. **히어로 키워드 밑줄**: 불빛이 지나가며 밑줄을 긋고, 잠시 유지 후 서서히 사라짐
4. **실사 장면**: PC 풀백(112%→100%) / 모바일 줌인(100%→112%)
5. **COMPANY**: 숫자 카운트업(작은 숫자부터 종료), 끝자리는 파칭코 릴처럼 회전 후 안착, 이후 수상 배지 순차 점멸
6. **호버**: 카드 사진 확대, COCO 카드 네이비 전환, INSIGHT 제목 불빛 밑줄, 버튼·링크 시안 발광, 문의 카드 번쩍
7. **모바일**: 커서 효과 없음, WORK·INSIGHT 가로 캐러셀, SOLUTION 가로형 리스트

## 퍼블리싱 시 참고

- 인트로는 첫 방문에만 노출하고, 클릭 시 건너뛰기 지원
- Pretendard는 다이내믹 서브셋 버전 사용 권장 (현재 전체 폰트 2MB)
- 히어로 영상은 해당 장면 직전 로드, 화면 아래 이미지는 지연 로드
- 이 저장소의 페이지는 디자인 시안용이며, 실제 사이트 코드는 퍼블리싱 단계에서 새로 작성합니다
